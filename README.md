# School Search — каталог школ и детских садов

Многостраничный сайт для выбора частной школы или детского сада. Каталог помогает сравнивать организации по стоимости, местоположению и формату обучения, а подробные страницы — знакомиться с условиями и пространством перед обращением.

**[Открыть сайт →](https://zhigunovme.github.io/schoolsearch/)**

## Возможности

- **Два каталога:** школы и детские сады с отдельными страницами организаций.
- **Поиск без перезагрузки:** по названию, описанию и городу, с обновлением результатов при вводе.
- **Фильтры:** город, район, бюджет, формат, язык занятий и направление.
- **Сортировка:** по названию и стоимости в обоих направлениях.
- **Понятные состояния каталога:** количество найденных организаций, сообщение при отсутствии результатов и сброс фильтров.
- **Страница организации:** характеристики, стоимость, фотогалерея, карта, предпросмотр отзыва и похожие варианты.
- **Форма добавления организации:** проверка обязательных полей, длины описания и формата телефона.

## Технические решения

HTML5, CSS3 и JavaScript без сторонних JavaScript-библиотек. Данные организаций вынесены в отдельный файл, а общая логика используется на страницах каталогов и карточек.

Вёрстка адаптируется к мобильным экранам: навигация и панель фильтров раскрываются по кнопке. Поисковый запрос и выбранный город сохраняются в адресе страницы — ссылкой на такую выборку можно поделиться.

Для изображений используются WebP, варианты разрешения через `srcset`, отложенная загрузка и заданные размеры. Шрифты подключены локально в WOFF2. Статические страницы не требуют серверного рендеринга или базы данных.

В интерфейсе предусмотрены видимые состояния фокуса, ARIA-атрибуты, закрытие мобильного меню клавишей Escape и учёт настройки уменьшения анимации. Пользовательский текст в предпросмотре отзыва экранируется перед выводом.

## Что показывает проект

Разработку многостраничного интерфейса с общей моделью данных: поиск, комбинирование фильтров, сортировку, обновление карточек и обработку пустых состояний. Внимание уделено удобству на небольших экранах, загрузке изображений и деталям взаимодействия с формами.

## Демо

Каталог работает с локальным набором данных. Форма добавления организации демонстрирует проверку полей и окно подтверждения, без отправки заявки. Отзыв отображается как предпросмотр. Карта использует внешний сервис Яндекса.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте [localhost:8000](http://localhost:8000/). Сборка и установка зависимостей не требуются.
